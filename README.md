# 🤖 Discord Raid Bot

A Discord bot that can spam messages using `/raid` command.

## ✨ Features
- `/raid` slash command
- Customizable spam message
- Adjustable spam count (1-20)
- Built-in rate limit protection
- Easy deployment on Render

## 🚀 Commands

### `/raid`
Start a spam raid in the current channel

**Options:**
- `message` (required) - The message to spam
- `count` (optional) - Number of times to spam (default: 5, max: 20)
